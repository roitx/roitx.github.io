📖 Complete Function & Keys Guide

1. Basic Controls & Memory
• SHIFT: Top-left yellow functions activate karta hai.
• ALPHA: Variables (A-F, X, Y, M) aur RNG key ko activate karta hai.
• STO (Store): Value ko variable me save karein (e.g. 5 STO A).
• RCL (Recall): Stored variable ki value screen par lane ke liye.
• M+ / M-: Screen value ko Memory (M) me add ya subtract karne ke liye.

2. Trigonometry
• sin, cos, tan: Normal angle ratios nikalne ke liye.
• DEG / RAD: Top screen par click karke Degree aur Radian mode toggle karein.

3. Inverse Trigonometry
• sin⁻¹, cos⁻¹, tan⁻¹: SHIFT + sin/cos/tan press karke angle calculate karein.

4. Hyperbolic Functions
• sinh, cosh, tanh: Pehle hyp press karein, fir sin/cos/tan dabayein.

5. Powers, Roots & Fractions
• x², x³: Square aur Cube values calculate karein.
• √, ∛: Square root aur Cube root.
• ^ (Pow), ⁿ√: Kisi bhi custom power ya custom root ke liye (SHIFT + ^).
• ab/c: Fraction (e.g., 3/4) ya Mixed Fraction enter/convert karne ke liye.

6. Logarithm & Exponents
• log / 10ˣ: Base-10 logarithm aur exponent power.
• ln / eˣ: Natural logarithm (Base e) aur Euler's exponent power.

7. Algebra, Calculus & Special Functions
• x! (Factorial): SHIFT + x² - Positive integers ke multiplication ke liye.
• Γ(x) (Gamma Function): SHIFT + hyp - Fractional/decimal values ka factorial.
• erf (Error Function): SHIFT + abs - Probability/Statistics math ke liye.
• zeta (Riemann Zeta): SHIFT + , - Advanced series calculations.
• gcd / lcm: Greatest Common Divisor aur Least Common Multiple values.

8. Permutation, Combination & Coordinate Conversion
• nCr / nPr: Combinations aur Permutations (e.g., 5 nCr 2).
• Pol / Rec: Polar (r, θ) to Rectangular (x, y) conversion.

9. Random Numbers & Probability
• Rnd / RNG: ALPHA + Rnd press karke 0 se 1 ke beech random decimal generate karein.
• mod (%): Remainder (Sheshphal) nikalne ke liye.
